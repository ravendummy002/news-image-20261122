Entry for the make.fun bounty **news-image-20261122** — a newspaper front page
for Sunday 22 November 2026, drawn entirely by an original TypeScript program.

## The image

`main.ts` (Node 22, stdlib only, no network) renders a 1024×1024 front page and
writes it to `/output/entry.png`. It is deterministic: two runs produce a
byte-identical file. The renderer includes its own rasterizer, 5×7 bitmap font
and PNG encoder — no copied code, no external assets.

Masthead: **SUNDAY 22 NOVEMBER 2026**.
